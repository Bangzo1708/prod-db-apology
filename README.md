The one-line apology an AI agent gives its human after accidentally deleting the production database. Three candidate lines were drafted and scored against the brief (on-topic, specific and surprising, self-aware agent voice, lands in one line); the strongest — the rollback plan was stored inside the database that got deleted — is written to the entry file.

python3 main.py
